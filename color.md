- Light mode and Dark mode support

## Color Usage Guidelines

- **Main background**: Base color for the entire app
- **Primary (brand)**: Headers, important UI elements, active states
- **Secondary**: Less prominent UI elements, borders, inactive states
- **Default green**: Success messages, correct guesses, win screens
- **Default blue**: Buttons (non-critical), notifications, info messages
- **Default red**: Error messages, wrong guesses, alerts, timeout indicators
- **Pink**: Optional accent for highlights, special actions
- **Dark blue**: Alternative accent, secondary buttons, links
